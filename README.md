# Portfolio — Thomas Pouly

Site portfolio personnel, construit avec Astro et Tailwind CSS.

## Développement local

```bash
npm install
npm run dev
```

## Personnalisation

Tout le contenu se règle dans `src/config.ts` :

- informations personnelles
- liens sociaux
- à propos, compétences, projets, expérience, formation
- couleur d'accent

## Build

```bash
npm run build
npm run preview
```
